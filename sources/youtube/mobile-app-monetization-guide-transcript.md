## Key Takeaways

### Tech Stack Formula
- **Frontend**: React Native + Expo
- **Backend**: Convex (real-time database)
- **Auth**: Clerk / WorkOS / BetterAuth (your choice)
- **Platform Focus**: iOS first (paying customers)

### Marketing Formula
1. **TikTok is #1**: Normies use TikTok as search engine
2. **Daily content**: Create one TikTok video per day minimum
3. **Partner up**: If you can't create content, find someone who can
4. **Follow trends**: Build apps around trending behaviors

### Success Formula
1. Build simple template/tech stack
2. Ship multiple apps quickly
3. Create TikTok/Instagram content consistently
4. Iterate based on failures
5. Keep shipping until one hits

### Proven Examples
- **Candle**: Hundreds of thousands of users, high MRR (React Native + Expo + Convex)
- **Jack's Couples App**: 5K MRR in 15 days
- **Timeout App**: Built quickly based on trending "raw dogging boredom" concept
- **Altoia**: Travel app (launching soon)

### Strategic Insights
- **Niche selection matters**: Couples niche is booming
- **Twitter ≠ target audience**: Devs will build it themselves, normies will pay
- **Mobile > Web for B2C**: Normies prefer mobile apps over web apps
- **Volume strategy**: Throw many shots, learn from failures, one will hit
- **Complementary skills**: Partner with people who have skills you lack

### The Million Dollar Operation
1. Build the app (you handle tech)
2. Market on TikTok/Instagram (partner handles content)
3. Keep doing both until revenue flows
